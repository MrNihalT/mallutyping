# MalType

A modern Malayalam typing learning platform inspired by TypingClub and Monkeytype.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Supabase
- Framer Motion

## Features

- Structured lessons
- Malayalam InScript keyboard
- Finger animations
- Progress tracking
- Statistics
- Sound effects
